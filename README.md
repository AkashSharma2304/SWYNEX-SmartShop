# 🛒 SmartShop – E-commerce Product Explorer

<p align="center">
  <img src="logo.png" width="180" alt="SmartShop Logo">
</p>

SmartShop is a responsive e-commerce product explorer built using HTML, CSS, and JavaScript. It allows users to browse products, search for items, filter by categories, sort products, and manage their shopping cart.

##  Features

- Fetch products from the DummyJSON API
- Search products by name
- Filter products by category
- Sort products by price and rating
- Pagination for browsing products
- Add products to the shopping cart
- Increase or decrease product quantity
- Remove products from the cart
- Calculate subtotal, delivery charges, and total amount
- Free delivery on orders of ₹999 or above
- Display product prices in Indian Rupees (INR)
- Save cart data using LocalStorage
- Responsive design for desktop and mobile devices

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- DummyJSON API
- LocalStorage

## 🌐 API Used

SmartShop fetches product data from the DummyJSON API:

https://dummyjson.com/products?limit=100

##  How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Browse products and try the shopping cart features.

##  Currency

Product prices are displayed in Indian Rupees (INR) using a conversion rate applied in the JavaScript code.
